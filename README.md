# homebrew-tap

Homebrew tap for [cryks](https://github.com/cryks)' apps.

## Usage

```sh
brew install cryks/tap/shepherd
```

| Cask | Description |
|------|-------------|
| [`shepherd`](https://github.com/cryks/shepherd) | Menu bar app that monitors coding agents running in herdr |

Cask versions are bumped automatically by each project's release workflow.
